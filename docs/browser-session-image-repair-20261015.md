# 网页会话与导入兼容说明

本文保留会话导入的技术边界，不公开个人账号、真实调用记录或部署现场信息。

## 会话字段

Access Token、网页 Session Token 和 OAuth Refresh Token 用途不同。导入时应保留来源格式中合法且受支持的完整会话字段，校验类型和长度；错误消息不得包含原始凭据。

账号能读取资料或刷新额度，不代表网页生图会话已经完整。只有在实际调用路径需要的字段已保存，并完成独立请求验证后，才能确认该账号适用于该路径。

## 安全恢复

恢复原生成请求应沿用原任务、账号和会话标识，查询最终事件及文件。恢复时不自动重发生成 POST，不用其他图片代替原任务结果。

## 验证

回归应覆盖完整 Session JSON、旧格式、非法输入、字段长度及错误脱敏。真实请求报告只保留结果类型、必要的阶段和是否取得有效文件；原始身份信息和会话副本留在受保护的本地位置，验证完成后及时清理。
