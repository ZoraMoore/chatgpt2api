# 发布源码快照与数据隔离

公开源码快照应只包含可分发代码、构建定义、合成测试夹具和通用文档，不复制运行数据。

## 导出范围

- 保留服务端模块、静态资源及对应的兼容扩展。
- 可构建前端与产物需要保持对应，保留第三方来源和许可证。
- 若运行容器包含工作目录中没有的模块，应先进行代码差异核对；不要把容器的配置和数据一起导出。

## 排除项

`.env`、`config.json`、`data/`、账号池、Token、Cookie、原始 HAR、日志、用户图片、数据卷和备份不得进入源码导出。

## 验证

比对导出源码与实际运行代码，记录差异，但不公开个人路径、镜像摘要、容器标识和部署时间。发布前扫描当前文件与历史中的敏感内容。
