# 管理功能与兼容验证说明

## 日志时间

日志列表使用明确的显示时区，兼容历史无时区记录与新格式。日期筛选遵循页面标注的时区；不通过批量改写历史日志来改变显示，也不改变删除所用的稳定 ID。

## 账号操作

账号行及批量操作面板提供受权限保护的维护入口。图像空间清理需先预览、再确认；自动清理默认关闭，按实际创建时间判断，未知时间不应作为可删除依据。

手动刷新 Access Token 依赖有效 Refresh Token；网页 Session Token 不等同于 OAuth Refresh Token。到期自动刷新、保活与清理任务应遵守账号状态、并发和开关，避免重复执行。

## 完整导入

支持的导入格式应保留合法的完整 credentials，校验外部输入，并避免旧凭据覆盖已保存的新凭据。身份不足时不凭邮箱猜测合并。管理接口返回必要状态，不在错误或事件桥中暴露凭据。

## 回归范围

使用合成账号和模拟写接口验证时区、单账号及跨页选择、清理确认、缺少 RT 的禁用提示、SPA 导航、手机布局和错误恢复。真实业务验证另行记录，不把模拟测试当作上游可用性证明。

公开说明不包含个人账号健康、数量、配额、日志统计或具体部署记录。
