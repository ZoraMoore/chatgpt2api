# 后台恢复、账号验证和选号容错修复

> **For agentic workers:** Implement this plan directly, task-by-task, in the current session. No separate execution sub-skill is required. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先保存修复前可部署源码，再修复四类已确认遗漏及相关诊断字段。
**Architecture:** 保留原账号、原会话与生成幂等约束。后台读取429在既有恢复期限内按恢复时间退避；账号验证所有权结束时保持异常/停用状态并正确进入等待；单账号预检只分配选号剩余时间的一部分，为备选保留机会；对外明确政策拒绝为终态。源站运行配置与数据不进入GitHub。
**Tech Stack:** Python unittest、SQLite、Docker Compose、GitHub Git API、Node内置测试。

用户要求最终图首次下载失败未登记后台恢复暂不修复；本轮不改该场景，不新增恢复任务或改变最终图选择契约。
