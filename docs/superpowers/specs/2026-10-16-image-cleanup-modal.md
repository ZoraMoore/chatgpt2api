# 图像空间清理弹窗

仅修改 Image 测试站。点击账号操作中的“清理图像空间”立即请求后台预览，在同一弹窗显示逐账号扫描数量、错误、清理与复扫进度。用户核对快照后勾选确认并执行。关闭弹窗不取消后台任务，可通过“查看清理任务”重新打开；刷新页面通过 sessionStorage 中的不含凭据的任务编号恢复查询，不重复提交。

账号列表增加跨分页全选入口，批量操作允许任意已选账号进入清理流程。完整全选使用 all_accounts=true，由后端在受理时固定支持的账号集合；局部选择允许最多 1000 个。OAuth 手动刷新及自动开关仍保留原来 20 个账号的限制，不扩大其他动作。任何预览失败仍禁止执行，展示具体账号错误。旧独立页面链接重定向到账户列表并打开预览弹窗。

沿用已有后台快照、单清理任务串行、分批删除、复扫确认规则。只对预览成功的完整快照执行，不纳入执行期间新增账号或图片。验证包含超过 20 个账号、全选快照、鉴权、确认门槛、失败/空结果/轮询中断/关闭重开/刷新恢复/移动端/SPA 导航。真实环境只进行预览，不删除用户图片。
