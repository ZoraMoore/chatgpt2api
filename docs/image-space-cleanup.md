# 号池图像空间清理

在「号池管理 → 清理图像空间」选择 1–20 个 ChatGPT 账号，先预览数量，再勾选确认并执行。Adobe 账号不参与此功能。页面复用管理面板登录，也可以输入管理密钥。

实现依据用户提供的 `delete_gpt_image_space.py`：使用图片库分页接口和 `delete-batch`，每批 25 张，等待 20 秒再完整复扫。这里只移入「最近删除」，不清空最近删除、不包含隐藏图片，也不会处理预览之后新增的图片。预览失败时整份预览不可执行；执行时某个账号失败不影响后续账号。

- 「接口接受」只表示上游逐项返回成功，不能证明图片已删除。
- 「确认移出」表示预览图片在最近一次完整列表复扫中已消失。
- 「快照剩余」表示最近一次完整复扫仍能看到的预览图片数；发生网络错误时可能是旧值，应结合失败说明重新预览。
- 分页空页继续读取；游标循环、字段异常、超过 100 页或 20000 张时停止，避免把不完整结果误报为成功。
- 最多复核 8 轮，单图最多删除 4 次；遇到 401/403 立即停止该账号，429 和服务端临时故障有限重试。

账号凭据和图片快照只在后端使用；新增管理接口返回不含 Token 的账号选择标识。网络异常和响应正文不会原样返回页面。请求复用号池的代理配置与浏览器 TLS 指纹。

## 管理接口

所有 `/api/accounts/image-space/` 接口都要求管理员 Bearer 密钥。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/accounts/image-space/accounts` | 获取可选择账号的 `id`、`label`、`type` |
| `POST /api/accounts/image-space/preview` | 请求体 `{"account_ids":["账号选择标识"]}`；返回任务 `id` |
| `GET /api/accounts/image-space/jobs/{id}` | 读取任务和各账号进度 |
| `POST /api/accounts/image-space/jobs/{id}/execute` | 请求体 `{"confirm":true}`，执行已预览的快照 |

任务使用进程内后台线程，同一时间最多运行一个预览或清理任务。预览和结果自最后更新起保留 30 分钟，最多保留 10 个任务。服务重启后任务记录消失，正在执行的任务被中断；请重新预览，不要根据旧进度推断剩余数量。当前部署为单 Uvicorn 进程；多进程部署前需将任务、锁和快照迁移到共享存储与任务队列。

当前仓库没有 Next 前端源文件，因此通过 `api/app.py` 为 HTML 注入独立的 `web/account-image-space.js`，入口支持客户端切换页面。操作页面是 `web/image-space.html`。将来恢复前端源码后可以将入口迁入原生组件。

## 验证

在安装项目开发依赖的隔离环境运行：

```bash
python -m unittest discover -s tests -p test_image_space.py -v
```

测试使用模拟上游，包括空页分页、异常列表、409、索引延迟、有限重试、分批大小、快照范围、凭据脱敏、管理员鉴权、预览到执行流程与重复提交。不会调用真实账号的删除接口。实际效果仍取决于 ChatGPT 未公开网页接口，接口变化时需重新核对。
