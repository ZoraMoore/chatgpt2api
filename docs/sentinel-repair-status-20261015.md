# 前置校验修复与验证边界

本文为通用技术说明，不表示任何个人部署的当前状态。

## 排查项目

- 前置校验输入、解析与异常处理是否完整。
- 浏览器身份、设备上下文及请求链是否一致。
- PoW 等计算是否设置输入长度、配置大小、尝试次数与时间预算。
- prepare 与后续请求是否使用同一轮合法上下文。

## 验证要求

针对已确认的协议差异建立独立回归，失败时停止错误链路，日志不记录凭据或校验原文。前置校验成功不等于实际图片生成成功。

候选版本需在隔离环境完成测试，再以授权测试请求确认终态和最终文件。个人账号信息、历史耗时、运行镜像摘要、容器 ID 和报告路径不属于公开文档内容。

相关方法见 [模型调用排查](account-model-invocation-diagnosis.md) 和 [浏览器协议对照](latest-har-alignment-20261015.md)。
