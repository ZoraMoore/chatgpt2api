# 实例间代码同步与数据保留

实例间同步只涉及明确选定的代码和静态资源；账号、客户密钥、配置、日志、用户图片及数据卷保持独立。

## 操作顺序

1. 记录目标实例的镜像、容器和挂载，备份前端及配置。
2. 确认来源版本和改动范围，检查是否存在在途任务。
3. 采用最小覆盖或叠加镜像，保留当前后端与安全更新。
4. 仅更新目标实例，不重建无关服务，不删除卷。
5. 核对代码、静态资源、配置与挂载，并完成必要的实际请求验证。

## 验收边界

`/version`、健康接口或模型目录返回成功只表示相应入口可访问。图片链路需取得同一次请求的终态并下载验证有效文件。

实际实例域名、账号数量、镜像标识、切换时间和请求结果保存在本地受保护台账；公开文档不提供个人现场的同步记录。
