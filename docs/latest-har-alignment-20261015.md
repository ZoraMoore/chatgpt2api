# 浏览器请求与服务端协议对照

## 使用边界

HAR 可能包含 Authorization、Cookie、会话标识、邮箱、附件 URL 和用户内容。原始文件不应进入公开仓库；测试夹具必须改为合成数据。

## 对照项目

1. 明确账号、工作区与模型上下文，但不公开真实标识。
2. 对比浏览器身份、设备信息及请求链内的一致性。
3. 对比前置校验、prepare、生成 POST、SSE 和最终结果查询的阶段顺序。
4. 对比参考图上传、处理完成确认、附件引用和尺寸等必要字段。
5. 将最终图片与预览、输入图片、中间工具产物区分开。

浏览器续聊样本不能证明首轮生图必须复用历史会话；单次错误也不能证明账号套餐不支持模型。修复优先选择已复现且有测试支撑的差异。

## 可公开的证据

只保留合成请求结构、必要状态码、事件类型和测试结论。实际请求编号、账号、设备、会话、附件及本机报告路径留在受保护的运维记录中。请求夹具见 `tests/fixtures/web_image_har_request.json`。
