# 图像空间清理弹窗

仅发布测试站 image.liunx.me，版本 `local/chatgpt2api-image:cleanup-modal-20261016`；主站未修改。发布前无在途生图请求，当前 1 个账号、密钥、配置、挂载、账号开关及 4 个工作线程保留。

## 使用

1. 单个账号：点击行内“操作”→“清理图像空间”，立即在弹窗请求后台预览并显示逐账号数量。
2. 多账号：勾选账号后打开“批量操作”；也可以点“全选账号”，跨分页选择全部支持清理的 ChatGPT 账号，再打开批量操作清理。
3. 预览成功后勾选确认，点击“确认清理预览图片”。弹窗显示清理、复核、确认移出数量、剩余数量及逐账号错误。任何预览失败或没有图片时都不能提交删除。
4. 关闭弹窗后任务继续执行；点“查看清理任务”重新打开。刷新页面只查询原任务，不自动重新提交。连接出错时用“继续读取进度”；任务已过期时重新预览并确认。

清理不会跳转独立页面。历史 `/accounts/image-space?accounts=...` 链接重定向到账户列表并自动打开对应预览弹窗。没有执行前确认，不会删除图片。

## 边界

- 全选使用后端受理时的账号集合，之后新增的账号不会纳入本次任务；Adobe 账号不属于该接口范围。
- 全选不受原 20 个账号限制；非全选的一次明确选择最多 1000 个。其他账号操作的原有限制保持不变。
- 沿用原预览快照、分批移入最近删除和复扫确认逻辑。任务期间新增图片不纳入删除。
- 任务存于服务内存，后台重启或超过保留时间会过期。浏览器仅保存任务 ID 和不可逆账号引用，不保存凭据。
