# 账号图像空间清理弹窗

## 操作流程

1. 从账号行或批量操作中打开清理弹窗，在当前页面请求后台预览。
2. 展示逐账号数量、失败原因和作用范围；有可执行预览时才允许确认。
3. 用户勾选确认后执行同一个预览任务，按真实结果显示进度。
4. 关闭弹窗不表示取消后台任务；重新打开只查询原任务。

旧 `/accounts/image-space?accounts=...` 链接可转到账号列表并打开对应面板。刷新和连接恢复不得自动重复执行清理。

## 边界

- 批量范围以提交时确认的账号集合为准，之后新增的账号或图片不纳入旧快照。
- 不支持的账号来源应说明原因。
- 任务可能在服务重启或保留期结束后失效；过期需重新预览并确认。
- 浏览器仅保存必要的任务 ID 和不可逆账号引用，不保存凭据。

## 验证

通过合成任务覆盖预览、确认、关闭重开、刷新恢复、重复点击、网络失败、过期、权限和手机布局。验证时不操作真实账号数据。

具体部署镜像、容器状态、账号及图片数量和私有备份位置不写入公开文档。
