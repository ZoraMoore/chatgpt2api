# 出口时区探测与缓存

## 行为

出口时区用于请求上下文的一致性。以代理地址的 SHA-256 为缓存键，不同代理分别缓存，直连共用一项；内存与 `data/egress_timezones.json` 提供缓存，磁盘文件权限应限制为 0600。

缓存不保存代理地址、出口 IP、用户名、密码或账号令牌。外部探测失败应有超时和回退，不能阻断所有管理请求。

## 验证边界

测试应覆盖缓存隔离、时区偏移和夏令时、网络失败及并发读取。时区一致性只是请求上下文的一部分；即使前置接口成功，也不能据此宣称图片生成已经恢复。

部署时基于已验证镜像做最小变更，保留配置和数据。真实域名、账号数量、镜像标签、请求耗时及探测报告位置应记录在本地运维台账，不写入公开说明。
